# README artwork

The images used by the front-page `README.md`.

| File | Used for | Replace with |
|---|---|---|
| `banner.png` | The hero image at the top | Generated from the app's own icon, terrain picture and region shapes; keep, or a new design at about 1600 x 520 |
| `chip-top-*.png` and `chip-*.png` (six each) | The clickable chips: the small ones in a row under the banner, the others, all one size with the label wrapped, in the README's "Design choices" table; each links to its row | Generated by `make_art.py` from its `CHIPS` list; change the list, not the files. Saved at twice the size they show (the README sets the display height or width), so they stay sharp on high-resolution screens; the font is Inter SemiBold. Keep the order in step with the table's rows |
| `divider.png` | The gradient rule between sections | Keep |
| `icon.png` | The footer icon | Keep (the app's launcher icon) |
| `screen-map.png`, `screen-station-card.png`, `screen-elevation-bands.png`, `screen-elevation-north.png`, `screen-elevation-coast.png` | The five phone screenshots in the "Screens" gallery (three on the first row, two on the second) | Real screenshots of the app (Davis, SF Bay Area), taken on a phone, with the status bar and navigation bar cropped off and scaled to 540 px wide; kept under about 400 KB each. To change one, replace the file (same name) or edit its `src` and caption in the README |

`make_icon.py` draws the launcher icon (a sun, a small cloud and snow-capped mountains over a green hill, in a cartoon style
with thick navy outlines, on a blue sky) and writes every file that comes from it: the adaptive icon's vector layers in `app/src/main/res/drawable/`, the
themed (monochrome) layer, the Android 7 fallback images in `mipmap-*` and the 512 px Play Store icon. The vector files are
generated, so change the script, not them. Run it before `make_art.py`, which reads the Play Store icon.

`make_art.py` generates the banner, chips, divider and footer icon (needs Pillow). It reads the app's launcher icon
(`app/src/main/ic_launcher-playstore.png`), the statewide terrain picture (`app/src/main/assets/terrain/california.webp`) and
California's region shapes and colors from `StateUsaCA.kt`, so the banner follows the app. Run it from this folder after
changing the app's name or colors: `python3 make_art.py`. The name and tagline are drawn into the banner as pixels, so a
rename means running it again (and searching the README for the old name). The screenshots are real captures, not generated;
replace them by hand. Short animated clips (a GIF is shown inline by GitHub; keep each to about 5 seconds and a few MB) are planned for a later version.

Tips: take screenshots in light mode with nothing personal on screen, and keep each PNG under about 400 KB so the page loads
fast (an optimizer such as `pngquant` or Squoosh helps).
